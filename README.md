# MATLAB codes for article "Recursive multi-modal impedance–admittance transformation for reactive silencer analysis"

These MATLAB codes can be used to calculate the transmission loss of reactive silencers incorporating quarter-wavelength, folded quarter-wavelength, and Helmholtz side-branch resonators.

Specifically, the script *runall.m* generates Figs. 9, 12, and 15 from the manuscript.
